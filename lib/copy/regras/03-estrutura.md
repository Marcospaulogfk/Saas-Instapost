# ESTRUTURA DO CARROSSEL

## Arco narrativo por objetivo

- **vender (AIDA):** S1 capa-gancho → S2-3 problema concreto → S4-5 mecanismo / desejo → S(n-1) prova/resultado → S(n) CTA direto
- **informar:** S1 capa com promessa específica ("3 erros que matam X") → slides com 1 ponto cada (concreto, com exemplo) → S(n) recap + CTA suave (salvar/comentar)
- **engajar:** S1 pergunta que incomoda → 2-3 slides desenvolvendo opinião com voz própria → S(n) chamada pra opinião na DM/comentário
- **comunidade:** S1 manifesto curto → 2-3 slides com vulnerabilidade real → S(n) chamado coletivo

## Regras de sequência

- Slide 0 = CAPA (gancho principal). Último slide = CTA / conclusão.
- Slide 1 = REHOOK: dor + custo + promessa específica. NUNCA apresentação pessoal, agenda ou índice; é o maior ponto de abandono evitável do carrossel. Ele também é re-servido como capa pelo algoritmo, então precisa se sustentar sozinho.
- A ideia MAIS FORTE vai no slide 2 (o primeiro do corpo), não no final: quem abandona no meio nunca vê o final.
- **Continuidade obrigatória.** O carrossel é UM texto dividido em slides, não uma lista de frases soltas. Cada slide do corpo retoma o que o anterior deixou em aberto e avança um passo. Teste: lendo só os corpos em sequência, tem que dar um parágrafo coerente.
- **Todo slide do corpo termina com uma PONTE pro próximo** (exceto o último, que fecha). A ponte é a última frase do corpo e precisa criar vontade de arrastar: uma consequência anunciada ("e é aí que o custo dobra"), uma pergunta que o próximo slide responde ("mas por que ninguém corrige isso?"), um contraste pendente ("só que o problema nem é esse"), ou uma promessa específica ("o número do próximo slide explica"). Varie o tipo de ponte: a mesma construção em dois slides seguidos vira maneirismo.
- Nada de fechamento no meio: "E é isso." / "Simples assim." / "Fica a dica." matam o arraste. Frase que fecha só aparece no último slide.
- Último slide = UM único pedido. Empilhar salva+comenta+compartilha derruba a conversão de todos.
- Se o briefing for vago/curto, prefira ser específico em UMA direção (chuta uma boa) do que genérico em todas.
